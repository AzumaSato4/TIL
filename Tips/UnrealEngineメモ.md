# Unreal Engine 5メモ

## 接頭辞

- SM → スタティックメッシュ
- SK → スケルタルメッシュ
- SKEL → スケルトン
- PHYS → 物理アセット
- T → テクスチャ
- M → マテリアル
- UCX → 凸型のコリジョン
- USP → スフィア型のコリジョン
- UCP → カプセル型のコリジョン
- UBX → ボックス型のコリジョン

## グレーボックス

- モデリングモードで作成
- 形状、マテリアルを変更も簡単にできる
- PolyEdでより細かく形状を編集
- PolyEd>Extrudeで面押し出し
- PolyEd>Insert Edge Loopでエッジを挿入
- PolyEd>Insert Edgeで好きな位置にエッジを挿入（斜めなど）
- MshBoolで2つのオブジェクトを選びくり抜く
- Mergeで2つのオブジェクトを合成（1つのオブジェクトに）
- Pivotでオブジェクトの基準点を変更

## アセット

### ソースアセットの規格

#### 2Dテクスチャ

- ファイル形式：.bmp .float .pcx .png .psd .tga .jpg .exr
- 解像度：画像の幅や高さが2の倍数（32,64,1024,2048など）ピクセルであること

#### スタティックメッシュ

- ファイル形式：FBX
- スケール：1UU = 1cm
- モデル原点：通常、オブジェクトの下部の中央
- 方向：前面が正のX軸方向（実際はY軸方向になっているものが多い）
- コリジョン：ソースアセットの段階でコリジョンをつけておくことができる

#### スケルタルメッシュ

- ファイル形式：FBX
- スケール：1UU = 1cm
- モデル原点：足元
- 方向：前面が正のX軸方向（実際はY軸方向になっているものが多い）
- コリジョン：物理アセットでつけるため不要

### インポート

方法A：コンテンツブラウザのツールバーでインポートボタンをクリックしファイルを指定  
方法B：エクスプローラーからファイルをコンテンツブラウザにドラッグ＆ドロップ

## コリジョン

- コリジョン＝当たり判定
- モデリングで作ったメッシュはデフォルトで複雑なコリジョンを利用する設定になっている → 詳細パネルの「Collision Complexity」で変更可能
